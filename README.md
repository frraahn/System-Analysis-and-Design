# 📊 System Analysis and Design Course Portfolio (SECR2613 / SECP2613)

Welcome to my repository for the **System Analysis and Design (WBL)** course at Universiti Teknologi Malaysia (UTM). This space serves as a portfolio documenting our team-based system blueprint specifications alongside our practical coursework, methodology studies, and industrial research.

---

## 📂 Repository Structure & Portfolio Breakdown

### 🔹 Project: Lembaga Koperasi Kakitangan KADA Automated System (Group Team: G1)
* **General Summary:** As a system analysis team, we designed a comprehensive system blueprint to automate membership profiles and loan processing for Koperasi KADA. We analyzed stakeholder business logic to establish context-level layouts, planned explicit system interaction tracks using detailed user interface flow mockups, and mapped out data processing requirements to safely manage cooperative registrations, automated financial approvals, and internal administrative audits.
* **Core Deliverables:**
  * End-to-End System Architecture Design Blueprint

### 🔹 Lab Work & Assignments: Systems Engineering & Industrial Analysis
* **General Summary:** A collection of individual and group practical assessments focused on modeling software architectures and evaluating economic feasibility. The work spans calculating project timelines using critical path PERT charts, modeling multi-tier process boundaries via Context and Level 0 Data Flow Diagrams (DFD), authoring research papers on the System Development Life Cycle (SDLC), and analyzing modern corporate Agile/Waterfall execution trends through interactive seminars with industry experts.
* **Core Deliverables:**
  * Project Scheduling & Feasibility Management Studies
  * Data Flow Diagram (DFD) Engineering & Process Architecture
  * SDLC Phase Management & Structural Techniques Paper
  * Industry Seminar Report: Real-World Enterprise Project Management

## 💡 Course Reflection & Key Takeaways
This course provided me with a clear roadmap for turning ambiguous real-world business challenges into structured, developer-ready software specifications. Working on the Koperasi KADA automated system taught me how to approach software creation systematically using feasibility assessments to justify investments, Data Flow Diagrams to map information movement, and user interface mockups to match end-user needs. Exploring the SDLC phases and attending the industry expert seminar highlighted the practical importance of flexible project frameworks like Agile and Scrum in managing risks and keeping development teams aligned. Ultimately, this integration of visual system modeling and industry-standard project management has given me the confidence to analyze, design, and plan scalable software systems effectively.
